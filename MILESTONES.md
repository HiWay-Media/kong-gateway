# Milestones

The milestone plan lives in [`docs/milestones.md`](docs/milestones.md), published at
<https://hiway-media.github.io/kong-gateway/milestones/>.

The state it describes is not authoritative by itself — `./tests/run.sh` is. Every milestone has a
file in `tests/milestones/` holding its exit criterion in executable form; the page narrates what
the tests enforce, and the two are updated in the same commit.
